# Media files used by the pages

The pages load images and audio from the same folder. These files are **not in this repo** because the songs, album covers and artist photos belong to their owners. Put your own files here with these names (or change the names in the HTML) to see the full site.

## main.html
- Logo and slideshow: `logo.jpg`, `ig1.jpg` to `ig7.jpg`
- Language cards: `telugu.jpeg`, `tamil.jpeg`, `kannada.jpeg`, `malayalam.jpeg`, `hindi.jpeg`, `english.jpeg`
- New release covers: `hayyoda.jpeg`, `aradhya.jpeg`, `jhumka.jpeg`, `kalapara.jpeg`, `hukum.jpeg`, `vishwak.jpeg`
- New release audio: `hayoda.mp3`, `Aradhya.mp3`, `What Jhumka.mp3`, `Kalapakkara.mp3`, `hukumsong.mp3`, `Suttamla Soosi.mp3`
- Artist photos: `anirudh.jpg`, `spb.jpg`, `rahman.jpg`, `arjith.jpg`, `sunitha.jpg`, `shreya.jpg`
- Genre covers: `90s.jpg`, `mass.jpg`, `rom.webp`, `break.png`, `hanuman.webp`, `work.jpeg`

## romanticsongs.html
- Background: `songlistbg.jpeg`
- One cover image and one `.mp3` per song (see the `<img src>` and `<audio src>` lines)
